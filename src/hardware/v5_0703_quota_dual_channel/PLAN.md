# 中心径向拖拽菜单交互规划

## 背景

0630 版本的菜单使用 6 个圆形按钮环绕中心，用户点击按钮进入子页面。该方式稳定但缺乏"圆屏设备直觉"和记忆点。

本版本（0701）将菜单交互升级为**中心径向拖拽**：用户从中心圆按下，向某个方向拖拽，释放即进入对应子页面。拖拽过程有实时高亮和弹出动画，符合圆屏设备的径向交互直觉。

## 交互设计

### 触发区
- **中心圆**（半径 60px，圆心 233,233）：拖拽起点
- 用户必须在中心圆内按下才开始拖拽（避免误触）
- 中心圆外按下 = 普通点击（无效果或返回 Ready）

### 拖拽逻辑
1. **按下**：记录起点 (sx, sy)，必须在中心圆内
2. **移动**：计算当前触点相对中心的角度 θ
   - 6 个方向（每 60° 一个）：上 / 右上 / 右下 / 下 / 左下 / 左上
   - 根据角度确定当前高亮项 `drag_idx`（0-5 或 -1=无）
   - 拖拽距离 > 30px 才开始选方向（死区，避免抖动）
   - 高亮项向外弹出 16px（沿径向方向位移）
3. **释放**：
   - 若 `drag_idx >= 0`：进入对应子页面
   - 若 `drag_idx == -1`（距离不足或回到中心）：取消，不进入
4. **视觉反馈**：
   - 中心圆显示当前高亮项的中文名（scale=1）
   - 高亮项：亮绿边框 + 向外弹出 + 指示线连接中心到该项
   - 非高亮项：暗灰边框 + 原位
   - 拖拽时中心圆变暗，显示"松开进入"提示

### 方向映射（6 个扇区，每 60°）

```
方向角度 (0°=右, 逆时针):
  -90° ~ -30°  → 上 (状态)
  -30° ~  30°  → 右上 (蜘蛛)
   30° ~  90°  → 右下 (告警)
   90° ~ 150°  → 下 (能量)
  150° ~ 210°  → 左下 (设置)
  210° ~ 270°  → 左上 (关于)
```

实际用 atan2(dy, dx) 计算，dy 屏幕坐标向下为正，需取反。

### 菜单项位置（与 0630 一致，作为弹出终点）

| # | 方向 | 基础位置 | 弹出位置（外移 16px） |
|---|---|---|---|
| 0 | 上 | (233, 103) | (233, 87) |
| 1 | 右上 | (363, 163) | (377, 153) |
| 2 | 右下 | (363, 303) | (377, 313) |
| 3 | 下 | (233, 363) | (233, 379) |
| 4 | 左下 | (103, 303) | (89, 313) |
| 5 | 左上 | (103, 163) | (89, 153) |

## 状态变量

```c
static int s_drag_active = 0;      /* 0=未拖拽, 1=拖拽中 */
static int s_drag_idx = -1;        /* 当前高亮方向 -1~5 */
static int s_drag_start_x, s_drag_start_y;
```

## 渲染

`draw_menu()` 根据 `s_drag_active` 和 `s_drag_idx` 绘制：
- 始终绘制 6 个按钮（基础位置或弹出位置）
- 拖拽中：绘制中心→高亮项的指示线，中心圆显示高亮项名称
- 非拖拽：中心圆显示"菜单"

## 触摸流程

```
PAGE_MENU 状态:
  touch_down:
    if 中心圆内:
      s_drag_active = 1
      s_drag_idx = -1
    else:
      忽略（或视为点击外部，不处理）
  touch_move (s_drag_active):
    计算角度 → s_drag_idx
  touch_up:
    if s_drag_active && s_drag_idx >= 0:
      进入 s_menu_items[s_drag_idx].target_page
    s_drag_active = 0
    s_drag_idx = -1
```

## 与 0630 版本的差异

| 方面 | 0630 | 0701 |
|---|---|---|
| 菜单触发 | 点击按钮 | 中心拖拽 |
| 高亮 | 按下时 hit_test | 拖拽角度计算 |
| 弹出动画 | 无 | 高亮项外移 16px |
| 指示线 | 无 | 中心→高亮项 |
| 中心圆 | "菜单"文字 | 拖拽中显示当前项名 |
| 记忆点 | 弱 | 强（径向拖拽符合圆屏直觉） |

## 兼容性

- 保留长按 800ms 回 Ready
- 保留上滑返回上一级（Menu 上滑 → Ready）
- 其他页面（Status/Spider/Alert/Energy/Settings/About）逻辑不变
- 资源格式、分区表、字库不变，可复用 0630 的 states_anim.bin 和 font_atlas.bin

## 风险与回退

- 若拖拽角度计算不稳定，可加大死区（30→50px）
- 若误触严重，可要求拖拽距离 > 50px 才生效
- 回退：直接使用 0630_demo_round_ui_10states_anim 版本
