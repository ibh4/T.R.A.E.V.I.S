# 0701 中心径向拖拽菜单 - 硬件说明

## 概述

基于 0630 演示版圆屏 UI 升级菜单交互，将"点击圆形按钮"改为"中心径向拖拽"，符合圆屏设备的径向交互直觉，增强演示记忆点。

## 交互方式

### 中心径向拖拽菜单
1. 用户在**中心圆**（半径 60px）内按下
2. 向 6 个方向之一拖拽（上/右上/右下/下/左下/左上）
3. 拖拽过程中实时高亮对应方向的菜单项：
   - 高亮项沿径向方向**外移 16px**（弹出动画）
   - 中心→高亮项绘制**亮绿指示线**
   - 中心圆显示**当前高亮项中文名**
4. 释放即进入对应子页面

### 方向映射（6 扇区，每 60°）

```
        上 (状态)
       /        \
  关于(左上)  蜘蛛(右上)
      |          |
  设置(左下)  告警(右下)
       \        /
        下 (能量)
```

角度计算：`atan2(dy, dx) * 180/π`，dy 屏幕坐标向下为正

| 方向 | 角度范围 | 菜单项 |
|---|---|---|
| 上 | -120° ~ -60° | 状态 |
| 右上 | -60° ~ 0° | 蜘蛛 |
| 右下 | 0° ~ 60° | 告警 |
| 下 | 60° ~ 120° | 能量 |
| 左下 | 120° ~ 180° | 设置 |
| 左上 | -180° ~ -120° | 关于 |

### 死区设计
- 拖拽距离 < 30px 不选方向（避免抖动）
- 拖拽后回到中心（距离 < 30px）= 取消选择

## 兼容性

- **点击按钮**：中心圆外按下仍支持点击 6 个按钮（兼容旧交互）
- **上滑返回**：Menu 上滑 → Ready（保留）
- **长按回 Ready**：任意页面长按 800ms（保留）
- **其他页面**：Status/Spider/Alert/Energy/Settings/About 逻辑不变

## 状态变量

```c
static int s_drag_active = 0;        /* 0=未拖拽, 1=拖拽中 */
static int s_drag_idx = -1;          /* 当前高亮方向 -1~5 */
#define DRAG_CENTER_RADIUS 60        /* 中心圆半径 */
#define DRAG_DEAD_ZONE 30            /* 死区 */
#define DRAG_POP_OFFSET 16           /* 高亮项弹出距离 */
```

## 视觉反馈

| 状态 | 中心圆 | 菜单项 | 指示线 |
|---|---|---|---|
| 未拖拽 | 绿圈 + "菜单" | 暗灰边框，原位 | 无 |
| 拖拽中（有方向） | 亮绿圈 + 当前项名 | 高亮项亮绿边框+外移16px | 中心→高亮项亮绿线 |
| 拖拽中（死区内） | 亮绿圈 + "菜单" | 全部原位 | 无 |

## 编译与烧录

### 资源复用
本版本与 0630 共用资源文件：
- `states_anim.bin` (13.5MB, 10 状态 × 12 帧)
- `font_atlas.bin` (164KB, 164 字 × 32×32)

### 编译
```bash
# 需在含 BSP components 的工程目录编译
cd <工程目录>
idf.py build
```

### 烧录
```bash
idf.py -p /dev/cu.usbmodem21101 flash
```

烧录地址：
- bootloader @ 0x0
- partition-table @ 0x8000
- traepal_player.bin @ 0x10000 (app, ~296KB)
- states_anim.bin @ 0x410000 (10 状态动画, 13.5MB)
- font_atlas.bin @ 0x1210000 (字库, 164KB)

## 与 0630 版本差异

| 方面 | 0630 | 0701 |
|---|---|---|
| 菜单触发 | 点击按钮 | 中心拖拽（兼容点击） |
| 高亮方式 | 按下时 hit_test | 拖拽角度计算 |
| 弹出动画 | 无 | 高亮项外移 16px |
| 指示线 | 无 | 中心→高亮项亮绿线 |
| 中心圆 | 固定"菜单" | 拖拽中显示当前项名 |
| 记忆点 | 弱 | 强（径向拖拽符合圆屏直觉） |

## 演示流程

```
开机 → Connect(1.5s) → Ready
  → 上滑 → Menu
    → 中心圆按下，拖拽到方向:
      上 → Status (10 状态左右滑)
      右上 → Spider (50fps 加速)
      右下 → Alert (bug↔fix 动画)
      下 → Energy (三状态轮播)
      左下 → Settings (假数据)
      左上 → About (项目信息)
    上滑 → 返回 Ready
  长按 → 返回 Ready (保险)
```

## 回退

如拖拽交互不稳定，可回退到 0630 版本（`src/hardware/0630_demo_round_ui_10states_anim/`），资源文件完全兼容。
